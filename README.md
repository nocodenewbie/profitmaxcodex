# ProfitMax Codex - Painel de Vendas

Aplicação frontend em React utilizando CDN. O painel oferece 10 ferramentas de vendas, cada uma com suporte a upload de CSV, entrada manual de dados, geração de relatórios em PDF e download de template CSV.

Interface em português (pt-BR) com formatação monetária no padrão `R$ 0.000,00`.

## Ferramentas
1. Controle de Vendas
2. Cadastro de Clientes
3. Cadastro de Produtos
4. Metas de Vendas
5. Controle de Descontos
6. Gestão de Campanhas
7. Análise de Faturamento
8. Controle de Despesas
9. Painel de Comissões
10. Relatórios Gerais

## Uso
Basta abrir `index.html` em um navegador para utilizar o painel.
